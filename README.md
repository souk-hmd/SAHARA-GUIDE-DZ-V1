# SAHARA GUIDE DZ PRO V1
نسخة ميدانية أولى قابلة للرفع على GitHub Pages.

## تشغيل
ارفع الملفات الخمسة إلى مستودع GitHub ثم فعّل GitHub Pages.

## مصادر الخريطة
- OpenStreetMap للطرق والأسماء والبيانات الجغرافية.
- Esri World Imagery لطبقة الصور الجوية/الفضائية.
- Overpass API لجلب الآبار والخدمات المسجلة في OpenStreetMap.

## تنبيه ميداني
بيانات الآبار والخدمات من OSM قد تكون قديمة أو ناقصة. لا تعتمد على أي بئر أو تحذير دون تحقق ميداني. هذه النسخة لا تدّعي أن كل الآبار أو المخاطر مكتملة.
