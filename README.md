# SAHARA GUIDE DZ V2

المرحلة الأولى: خريطة Leaflet + OpenStreetMap، صور Esri، GPS، بحث أماكن، حفظ نقاط محلي، مسافة، SOS، وواجهات المياه والمخاطر بدون بيانات وهمية.

## التشغيل
ارفع الملفات الخمسة إلى GitHub Pages وافتح الموقع عبر HTTPS.

## ملاحظات المصادر
- OpenStreetMap: بيانات وخرائط مع الإسناد المطلوب.
- Nominatim: البحث الجغرافي؛ يجب الالتزام بسياسة الاستخدام وعدم استعماله للاكمال التلقائي أو الطلبات الثقيلة.
- Esri World Imagery: طبقة صور جوية/فضائية؛ راجع شروط Esri المناسبة لاستخدامك التجاري قبل الإطلاق.

هذه النسخة ليست Offline Maps كاملة؛ التخزين غير المتصل للخرائط يحتاج مزود بلاطات مناسبًا أو حزمة بيانات يتم تجهيزها بطريقة متوافقة مع شروط المزود.
